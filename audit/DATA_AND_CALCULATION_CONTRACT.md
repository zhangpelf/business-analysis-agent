# 数据与计算契约

## 数据粒度与来源

一行 CSV 是一个 `period × channel` 经营观测。项目只随包提供 `business_analysis_agent/data/demo_metrics.csv`，其中全部为合成数据。任何上传数据都由使用者确认已脱敏、具备使用权，且不包含客户、订单明细、个人信息或受保密义务约束的数据。

| 字段 | 约束 | 用途 |
|---|---|---|
| `period` | 可解析日期 | 按期间汇总、排序和环比比较 |
| `channel` | 非空字符串 | 保留渠道粒度的原始观测 |
| `sessions` | 非负；每个期间汇总后大于零 | 转化率分母与流量驱动 |
| `orders` | 非负且不大于 `sessions`；每个期间汇总后大于零 | 转化率分子与客单价分母 |
| `revenue` | 非负；每个期间汇总后大于零 | 收入、客单价与贡献毛利 |
| `variable_cost` | 非负 | 贡献毛利 |
| `marketing_cost` | 非负 | 贡献毛利 |

任何一个期间整体没有会话、订单或收入都会被拒绝，而不是以零或无穷大继续计算。无经营活动期间应在上传前剔除或由上游系统另行标记。

## 期间 KPI

渠道行先按期间求和，再计算：

```text
conversion_rate = orders / sessions
AOV = revenue / orders
contribution_margin = revenue - variable_cost - marketing_cost
contribution_margin_rate = contribution_margin / revenue
```

环比字段由相邻的已排序期间计算。首期没有环比基准，因此其变化字段为空。

## 预警规则

当前版本使用透明、固定规则，便于人工核验：

- 收入环比不高于 `-10%`：`revenue_decline`；不高于 `-20%` 时为高严重度。
- 贡献毛利率环比变化不高于 `-5` 个百分点：`margin_rate_decline`；不高于 `-10` 个百分点时为高严重度。

阈值不是行业基准，也不自动证明异常原因。实际使用前应由业务方确认口径、季节性、促销和外部事件。

## 收入驱动分解与复算

令当期为 `t`，上一期为 `t-1`，会话量为 `S`，转化率为 `CR`，客单价为 `AOV`。顺序分解为：

```text
会话量影响 = (S_t - S_(t-1)) × CR_(t-1) × AOV_(t-1)
转化率影响 = S_t × (CR_t - CR_(t-1)) × AOV_(t-1)
客单价影响 = S_t × CR_t × (AOV_t - AOV_(t-1))
```

三项之和精确等于 `revenue_t - revenue_(t-1)`。每条驱动证据提供结构化 `revenue_impact` 字段，测试会逐期验证该等式。贡献毛利证据不填该字段，因为它同时反映收入、变动成本和营销成本变化。

## 建议与 LLM 边界

建议由证据中的负向变化映射到预定义的复核动作；它们不是模型预测、因果结论或自动执行命令。默认完全不调用 LLM。

只有明确配置 OpenAI-compatible 环境变量时，系统才将已生成的预警、证据和建议发送给外部摘要服务。摘要只能做定性表达，包含数字的返回会被拒绝；所有数值的唯一来源始终是确定性计算结果。
