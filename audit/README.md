# 经营分析 Agent 审计材料

本目录为 `business-analysis-agent` v0.1.0 的人工审阅入口。它服务于公开作品集的代码、数据边界、计算口径和可复现性审阅，不替代真实业务的财务、内控、合规或信息安全审计。

## 审计范围

- 输入 CSV 的字段、类型、非负约束和漏斗分母约束；
- 期间 KPI、预警阈值、收入驱动分解与建议之间的可追溯关系；
- FastAPI、Streamlit 和可选 LLM 摘要的边界；
- 本地测试、编译、构建产物和归档完整性。

## 目录导航

- [数据与计算契约](DATA_AND_CALCULATION_CONTRACT.md)：指标、分解公式、阈值和不可推断事项。
- [审计清单](AUDIT_CHECKLIST.md)：逐项复核步骤、已关闭问题和剩余限制。
- [验证记录](VERIFICATION.md)：本次归档所执行的命令及结果。

## 版本与可追溯性

- 应用版本：`0.1.0`（见 `pyproject.toml`）。
- 审计归档包含源代码、合成示例数据、测试、本文档和构建 wheel；归档根目录的 `SHA256SUMS` 用于文件完整性校验。
- 当前源目录尚未创建 Git 提交，因此校验和是本次归档的基线，而非可替代的版本控制历史。独立审阅通过后，应初始化首个提交并标记发布版本。

## 不在本次范围内

- 真实客户、订单、财务或投资数据的正确性、授权及脱敏质量；
- 真实业务归因、因果关系、预算或定价决策；
- 外部 LLM 服务、Docker 镜像、压力测试和生产部署；
- 权限、日志留存、数据保留和多用户隔离。这些需要明确的业务需求与部署环境后再审计。
